# 03 ｜ デザインシステム

FORTのブランドは「ミニマル・建築的・editorial」。装飾で飾らず、余白と
タイポグラフィで品を出す。Appleのような静けさを目指す。

---

## カラートークン

Tailwind の設定（`tailwind.config` または CSS変数）にこの値を登録して使う。

### ベース

| 用途 | 色 | 変数名の例 |
|------|-----|-----------|
| 背景 | `#F4F3EF` | `--bg` |
| カード面 | `#FFFFFF` | `--card` |
| 本文 | `#171717` | `--ink` |
| サブ文字 | `#777773` | `--sub` |
| 罫線 | `#D9D8D2` | `--line` |
| ダーク面（サイドバー等） | `#242424` | `--dark` |

### アクセント

| 用途 | 色 |
|------|-----|
| ブロンズ（主アクセント） | `#9A8060` |
| オリーブ（副アクセント） | `#6F7565` |

### 状態色（ステータス）

| 状態 | 文字色 | 背景色 |
|------|--------|--------|
| 正常・完了 | `#5B7355`（オリーブ） | `#EAEEE7` |
| 注意・保留 | `#B8A47E`（サンド） | `#F3EEE3` |
| 遅延 | `#B5714A`（テラコッタ） | `#F5E9E0` |
| 緊急・要確認 | `#A85A52`（くすんだ赤） | `#F3E4E2` |
| 無効・余裕 | `#6B6B67`（グレー） | `#ECEBE6` |

### 部署カラー

| 部署 | 色 |
|------|-----|
| 経営 | `#9A8060` |
| 営業 | `#6F7565` |
| 設計 | `#7C7A8A` |
| 工務 | `#8A7560` |
| 総務 | `#6B7A7C` |

### ダークモード

サイドバーは常に濃色。全体のダークモードも用意する（任意）。
ダーク時の背景 `#1A1A18`、カード `#242422`、本文 `#EDEBE5`。

> **青系は使わない。** リンクやボタンの「いかにもWeb」な青は避け、ブロンズ／墨色で。

## タイポグラフィ

| 用途 | フォント |
|------|----------|
| 英字・数字の見出し／ラベル | **Inter**（600〜800） |
| 和文の本文・UI | **Noto Sans JP** / **Zen Kaku Gothic New** |

- 英字ラベルは字間を広めに（letter-spacing 0.06〜0.14em）、小さく、上品に。
  例：セクション見出しに `DASHBOARD` `STAFF` のような英字を添える。
- 数字（KPIの大きな数値など）は Inter の太字で、堂々と大きく。
- 日本語見出しは詰めすぎず、余白をとる。

## レイアウト・コンポーネント指針

- **角丸**：控えめ（6〜8px）。
- **影**：極薄（`0 1px 2px rgba(0,0,0,.04)` 程度）。ホバーで少しだけ持ち上げる。
- **余白**：ケチらない。要素同士の間、カード内padding を十分に。
- **罫線**：薄い罫線（`--line`）で区切る。濃い線は使わない。
- **カード**：白背景＋極薄罫線＋極薄影。これが基本単位。
- **リスト**：行間に薄い区切り線。ホバーでごく淡く背景色。
- **バッジ／ピル**：状態色の淡い背景＋濃いめの文字。小さく。
- **プログレスバー**：細く（高さ6px程度）、状態色で。

## ナビゲーション

- **PC**：左サイドバー（濃色 `#242424`）。折りたたみ可。
- **モバイル**：サイドバーは隠し、下部にボトムナビ＋ハンバーガー。
- ヘッダーに：現在地・日付・拠点切替（全社／岡山／福山）・通知・ユーザー。

## トーン

- 文言は簡潔に。過剰な説明や絵文字は避ける。
- 「Good morning, Hiroki.」のような、静かで少しだけパーソナルな挨拶は可。
- エラーや空状態も、素っ気なくしすぎず、次にどうすればいいかを一言添える。
