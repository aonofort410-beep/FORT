# FORT標準仕様Webガイド ページ構成（確定版）

前回の設計書（`brand-guide-standard-spec-site-design.md`）で定義したコンセプト・選定思想を土台に、指定された12ページの構成を確定する。

**前提の整理**
- 前回案にあった「環境・省エネ」の視点は独立ページとせず、性能ページの中に内包する。
- 前回案にあった「FAQ」は独立ページとせず、各ページの「6. お客様に伝えるべき一言」に疑問解消の要素を織り込む形で分散させる。
- 「掲載する標準仕様」は項目カテゴリの整理であり、実際のメーカー名・型番・数値は未確定（前回設計書 9章の確認事項どおり、実データの提供待ち）。ここでは「何を載せる欄か」を定義する。
- 「メインコピー」＝Webサイト上のキャッチコピー、「お客様に伝えるべき一言」＝営業・接客時にも使える、思想を一言に凝縮したトークポイント、として役割を分けている。

---

## TOP

1. **ページタイトル**：FORT STANDARD ｜ FORTが選ぶ、標準の理由
2. **メインコピー**：標準は、妥協ではなく、思考の結晶。
3. **このページで伝えること**：以降の全ページに共通する前提として、「標準仕様＝コストを抑えた最低ライン」ではなく「FORTが選び抜いた基準」であることを最初に宣言する。各カテゴリページの要約を見せ、全体像への期待値を作る。
4. **掲載する標準仕様**：各カテゴリ（性能・外装・内装・水まわり・収納・照明）の代表仕様を1点ずつ抜粋したハイライト（詳細は各ページに誘導）
5. **掲載する施工写真**：ブランドを象徴するヒーロービジュアル（外観・夕景）、各カテゴリを代表するディテールカットのサムネイル一覧（6〜8点程度）
6. **お客様に伝えるべき一言**：「このサイトに載っているのは、価格ではなく理由です。」
7. **CTA**：各カテゴリページへ（スクロール誘導）／資料請求・相談する（フッター共通導線）

## 性能

1. **ページタイトル**：性能｜見えない場所にこそ、確かな基準を
2. **メインコピー**：見えない場所こそ、いちばん妥協しない。
3. **このページで伝えること**：耐震・断熱・気密といった「住んでから初めて実感する」性能について、数値の高さだけでなく、なぜその水準を標準にしたか（家族の安全、四季を通じた快適性、資産価値の維持）を説明する。環境負荷・光熱費といった持続性の視点もここに含める。
4. **掲載する標準仕様**：耐震等級、耐風・耐積雪等級、断熱等級／UA値、気密性能（C値）、基礎・構造材のグレード、防蟻・防湿処理、（参考）長期優良住宅認定の対応状況
5. **掲載する施工写真**：上棟時の構造写真、耐震金物のクローズアップ、断熱材施工中のシーン、気密測定の様子、基礎工事の写真
6. **お客様に伝えるべき一言**：「安心は、完成してからでは直せません。」
7. **CTA**：性能について詳しく相談する／資料で数値を確認する

## 外装

1. **ページタイトル**：外装｜十年後も美しくあるための素材選び
2. **メインコピー**：十年後も、美しくあるために。
3. **このページで伝えること**：外壁・屋根・外部建具の選定が、意匠性と耐候性・メンテナンス性のバランスで決まっていることを伝える。街並みに対する責任（経年後の見た目）という視点も加える。
4. **掲載する標準仕様**：外壁材の種類・耐久性・メンテナンスサイクル、屋根材、防水・シーリング仕様、軒天／破風などのディテール、外部サッシ・玄関ドアの断熱／防犯仕様
5. **掲載する施工写真**：外壁材のマクロ撮影、外観全景（複数実例）、防水シート・下地施工中の写真、可能であれば経年変化の比較写真
6. **お客様に伝えるべき一言**：「外観の美しさは、10年後も色褪せないよう選んでいます。」
7. **CTA**：外観の施工事例を見る（施工事例ページへ）／相談する

## 内装

1. **ページタイトル**：内装｜触れるたびに感じる、素材の質
2. **メインコピー**：触れるたびに、上質を感じる。
3. **このページで伝えること**：床・建具・造作・壁装など、日常的に手が触れる部分の素材選定基準を伝える。デザインの一貫性と、日々の使用に耐える実用性の両立という視点。
4. **掲載する標準仕様**：床材の種類・グレード、建具（ドア・引き戸）の仕様、造作家具、壁装仕上げ（クロス／塗装）、巾木・廻り縁などのディテール
5. **掲載する施工写真**：床材のクローズアップ、リビング全体カット、建具・造作家具のディテール、素材サンプルの比較写真
6. **お客様に伝えるべき一言**：「毎日触れる場所だからこそ、素材にこだわりました。」
7. **CTA**：内装コーディネート事例を見る／相談する

## キッチン

1. **ページタイトル**：キッチン｜家族の時間の中心に立つ基準
2. **メインコピー**：使いやすさは、選び抜いた結果。
3. **このページで伝えること**：キッチンが単なる設備ではなく、家事動線・家族とのコミュニケーションの中心であるという前提から、使い勝手・耐久性・意匠性のバランスで機種を選んでいることを伝える。
4. **掲載する標準仕様**：キッチン本体（グレード・レイアウトの考え方）、天板材質、収納容量・レイアウト、水栓仕様、レンジフード（換気）仕様
5. **掲載する施工写真**：キッチン全体カット、天板・水栓のディテール、収納内部、家族が調理・団らんするシーン
6. **お客様に伝えるべき一言**：「毎日の家事が、少しでも楽になるように選びました。」
7. **CTA**：ショールーム見学を予約する／相談する

## 浴室

1. **ページタイトル**：浴室｜一日の疲れを癒す基準
2. **メインコピー**：くつろぎに、妥協はいらない。
3. **このページで伝えること**：浴室は「くつろぎの場」であると同時に「ヒートショックなど安全上のリスクがある場」でもあるという二面性を踏まえ、断熱・保温性能とお手入れのしやすさを基準に選定していることを伝える。
4. **掲載する標準仕様**：浴室ユニット（サイズ・断熱グレード）、浴槽材質・保温性能、換気乾燥暖房機の有無、床の防滑仕様
5. **掲載する施工写真**：浴室全体カット、断熱・保温仕様のディテール、換気システムの写真
6. **お客様に伝えるべき一言**：「寒さも、お手入れの手間も、あらかじめ考えてあります。」
7. **CTA**：浴室のショールーム体験を予約する／相談する

## 洗面

1. **ページタイトル**：洗面｜身支度の時間を心地よく
2. **メインコピー**：小さな空間にも、こだわりを。
3. **このページで伝えること**：家族が朝夕に必ず使う場所として、収納力・お手入れのしやすさ・「見せる収納」としての意匠性を基準に選定していることを伝える。
4. **掲載する標準仕様**：洗面化粧台（サイズ・グレード）、天板材質、収納容量、鏡・照明仕様、水栓
5. **掲載する施工写真**：洗面台全体カット、収納内部、朝の身支度シーン
6. **お客様に伝えるべき一言**：「毎朝使う場所だから、丁寧に選びました。」
7. **CTA**：相談する／資料請求する

## トイレ

1. **ページタイトル**：トイレ｜清潔感と快適性の両立
2. **メインコピー**：見えない配慮こそ、標準に。
3. **このページで伝えること**：清潔さ・お手入れのしやすさ・節水性能という、目立たないが日々の満足度を左右する基準で機種を選んでいることを伝える。
4. **掲載する標準仕様**：便器のグレード、節水性能、お手入れのしやすさに関わる機能、収納・手洗いカウンターの有無
5. **掲載する施工写真**：トイレ空間全体カット、便器のディテール、収納・手洗いカウンター
6. **お客様に伝えるべき一言**：「清潔であることは、暮らしの基本だと考えています。」
7. **CTA**：相談する

## 収納

1. **ページタイトル**：収納｜暮らしを整える、見えない設計力
2. **メインコピー**：片づいた暮らしは、設計から生まれる。
3. **このページで伝えること**：収納は「量」ではなく「位置・動線」で決まるという設計思想を伝える。家事動線・来客動線を踏まえた収納配置が標準仕様に組み込まれていることを説明する。
4. **掲載する標準仕様**：各室収納の標準仕様（クローゼット、シューズクローク、パントリー等）、可変棚など可変性のある仕様
5. **掲載する施工写真**：各種収納の実例写真、収納内部の使い方が分かるカット
6. **お客様に伝えるべき一言**：「収納は、量より"置き場所"で決まります。」
7. **CTA**：間取り相談をする

---

## 照明

1. **ページタイトル**：照明｜光がつくる、空間の表情
2. **メインコピー**：灯りひとつで、暮らしが変わる。
3. **このページで伝えること**：照明計画が、機能性（明るさの確保）と情緒性（時間帯ごとの居心地）の両立という基準で標準設計されていることを伝える。省エネ性（LED標準化）にも触れる。
4. **掲載する標準仕様**：標準照明計画（ダウンライト配置の考え方）、LED仕様、調光・シーン照明の有無
5. **掲載する施工写真**：夜の室内照明カット（暮らしの雰囲気が伝わるもの）、間接照明のディテール、各部屋の照明配置写真
6. **お客様に伝えるべき一言**：「灯りの心地よさも、標準の一部だと考えています。」
7. **CTA**：照明プランについて相談する

## 施工事例

1. **ページタイトル**：施工事例｜標準仕様が、実際の住まいになるまで
2. **メインコピー**：基準は、一棟一棟の中に息づいている。
3. **このページで伝えること**：これまでのページで説明してきた「思想としての標準仕様」が、実在する住まいの中でどう組み合わさっているかを具体的に見せる。抽象的な説明を、現実の暮らしに接続する役割。
4. **掲載する標準仕様**：各事例で採用された仕様の要約タグ（外壁材／床材／キッチン等の組み合わせ一覧）
5. **掲載する施工写真**：事例ごとの外観・LDK・水まわりの写真一式、可能であれば施主の声とあわせたカット
6. **お客様に伝えるべき一言**：「この一棟にも、同じ基準が息づいています。」
7. **CTA**：他の事例を見る／この仕様で相談する

## 保証

1. **ページタイトル**：保証｜選んだ基準を、守りつづけるために
2. **メインコピー**：選んだ基準を、守りつづける約束。
3. **このページで伝えること**：標準仕様の選定は「引き渡した後も責任を持つ」という前提の上に成り立っていることを伝える。保証・点検体制は、これまでのページで説明してきた基準への"裏付け"として位置づける。
4. **掲載する標準仕様**：構造保証年数、設備保証（メーカー保証＋FORT独自保証の範囲）、定期点検のスケジュール、アフター対応体制
5. **掲載する施工写真**：定期点検の様子、アフターサービススタッフの対応シーン、引き渡し時の説明シーン
6. **お客様に伝えるべき一言**：「選んだ基準には、引き渡した後も責任を持ちます。」
7. **CTA**：保証内容について相談する／資料請求する

## ページ間の導線（補足）

- 全ページ共通で、末尾CTAの手前に「他カテゴリへの回遊リンク」を設置し、TOPに戻らずとも次のページへ進める構成にする。
- 「施工事例」ページは他の全カテゴリ（性能・外装・内装・水まわり・収納・照明）の"答え合わせ"としての役割を持つため、各カテゴリページの終盤から「施工事例で実例を見る」という導線を張る。
- 「保証」ページはCV（相談・資料請求）直前の"最後の後押し"として、他ページの終盤CTAの一つに「保証について知る」を選択肢として加えることを検討する。
