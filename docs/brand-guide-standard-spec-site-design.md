# FORT標準仕様ブランドガイドサイト 設計書

対象: FORT標準仕様を伝えるWebサイト（仮称「FORT STANDARD」）
前提: 実装前の設計フェーズ。コードは含まない。
参照: 既存LP `fort-series-lp.html`（FORT STYLE / PRO / DESIGN の3シリーズ紹介）のトーン＆マナーを踏襲する前提で設計。

---

## 1. サイト全体のコンセプト

**「何を使っているか」ではなく「なぜそれを選んだか」を伝えるサイト。**

住宅会社の標準仕様ページは、多くの場合「キッチン：〇〇社製／床材：〇〇社製」というメーカー名・型番の羅列（スペックシート）になりがちで、他社との違いが伝わりにくい。本サイトは仕様の一覧化ではなく、FORTが標準仕様を決める際に何を判断基準にしているか（意匠性・性能耐久・コストと暮らしやすさのバランスなど）という**選定思想**を主役に据える。

- コアメッセージ（案）：**「標準は、妥協の結果ではなく、思考の結晶。」**
- 個々の建材・設備は「思想を体現する実例」として扱い、常に「なぜこれを選んだか」の一文とセットで見せる。
- FORTの3シリーズ（STYLE / PRO / DESIGN）に共通する"土台の哲学"としての位置づけを明確にし、既存LPとは補完関係（LP＝商品ラインの案内、本サイト＝その裏側にある考え方の案内）にする。
- トーン＆マナーは既存LPの世界観（ゴールド×ダークブラウン、Serif見出し、静かで上質な余白）を継承し、ブランドの一貫性を担保する。

## 2. ターゲットユーザー

| # | ユーザー像 | 状態・関心 |
|---|---|---|
| A | 検討中の顧客（30〜40代、家族での新築検討層） | 複数社を比較中。「標準仕様」という言葉の裏にある考え方の違いで会社を選別したい。カタログ的な説明に疲れている。 |
| B | 契約済み・建築中の施主 | 自邸に採用された仕様の意味を家族や親族に説明したい。安心材料・納得材料が欲しい。 |
| C | 紹介経由の見込み客（提携店・不動産仲介など） | FORTを一言で説明する必要がある。ブランドの立ち位置を短時間で理解したい。 |
| D | 検索流入ユーザー（特定建材・性能ワードで来訪） | 「耐震等級」「断熱等級」などで検索。専門的な裏付けと、押し付けがましくない説明を求めている。 |

主軸はA（比較検討層）。B・Dは補助的だが、A向けに作られたコンテンツがそのままB・Dの目的も満たす設計にする。

## 3. ユーザーが見終わった後に感じてほしいこと

- 「FORTは仕様を"なんとなく"決めていない。一つひとつに理由がある」という**信頼**。
- 「標準仕様＝グレードが低い」ではなく、「標準仕様＝FORTが積み上げた最適解」という**認識の転換**。
- 他社比較の軸として、価格やスペック表ではなく「思想が違う」という**言語化できる差別化ポイント**を持ち帰ってもらう。
- 押しつけがましい説得ではなく、「筋が通っている」ことへの静かな納得。読後に「相談してみたい」という自然な次の一歩につながる状態。

## 4. サイトマップ

```
0. TOP（FORT STANDARD トップ）
├─ 1. FORTの標準仕様に対する考え方（選定思想ページ）
├─ 2. 構造・性能仕様（耐震・耐久・断熱の土台）
├─ 3. 外装・外まわり仕様（外壁・屋根・窓まわり）
├─ 4. 内装・素材仕様（床・建具・造作・塗装）
├─ 5. 設備仕様（キッチン・浴室・洗面・トイレ・空調換気）
├─ 6. 環境・省エネ仕様（断熱等級・創エネ・ZEH等の考え方）
├─ 7. よくある質問（標準とオプション／シリーズによる違い）
└─ 8. お問い合わせ・資料請求（CTA、独立ページ兼共通フッター導線）
```

- 2〜6は「カテゴリページ」として並列構造。全て1のページで提示する共通基準（意匠性／性能耐久／コスト・持続性など）に沿って説明することで、サイト全体に一貫したロジックを持たせる。
- 既存の `fort-series-lp` へは「この標準仕様は3シリーズどう受け継がれるか」という文脈で相互リンクする（本サイト→LPの `#fort-style` 等へ、LP→本サイトへ）。

## 6. 各ページのスクロール構成

既存LPと同じ「Hero→導入→本論→まとめ→CTA」という縦スクロール型の構成を踏襲しつつ、標準仕様サイト向けに再設計する。

### 0. TOP
1. Hero：コアメッセージのコピー＋世界観ビジュアル（モデルハウスの静的なディテールカット）
2. 導入文：「なぜこのサイトを作ったか」（メーカー名の羅列ではない旨を明言）
3. 選定思想への橋渡しカード（3〜4軸を先出しでチラ見せ）
4. カテゴリ一覧（5枚のカード：構造/外装/内装/設備/環境）
5. FORT3シリーズとの関係性の一言説明＋LPへのリンク
6. CTA（相談・資料請求）

### 1. 選定思想ページ
1. Hero：「標準は、妥協ではなく思考の結晶」ステートメント
2. 背景：一般的な「標準仕様＝グレード表」への問題提起
3. FORTの判断基準（3〜4軸を1軸ずつじっくり展開。例：意匠の一貫性／性能と安全の担保／永く使える耐久性／コストと暮らしやすさのバランス）
4. 各軸の判断がカテゴリページにどう反映されているかの索引（カテゴリへの導線）
5. まとめ＋CTA

### 2〜6. カテゴリページ（共通テンプレート）
1. Hero：カテゴリ名＋キャッチコピー＋象徴カット
2. 導入：このカテゴリでFORTが向き合っている課題・前提
3. 選定基準の適用：選定思想ページの軸をこのカテゴリでどう解釈したか（例：外装なら「意匠の一貫性×耐候性」）
4. 具体仕様の紹介：2〜4項目を「仕様＋写真＋なぜそれか」の一組で提示（メーカー名は補足情報として小さく添える程度に留める）
5. 現場・職人・設計者の声（一次情報での裏付け、任意）
6. シリーズ間の違い（STYLE/PRO/DESIGNでどう変わるか、変わらないか）
7. 他カテゴリへの回遊導線
8. CTA

### 7. FAQ
1. Hero：シンプルな見出し
2. 「標準仕様とオプションの違い」など構造的な疑問（アコーディオン形式）
3. カテゴリ別のよくある質問
4. CTA

### 8. CTA/お問い合わせ
1. Hero的な訴求文（既存LPの `fsl-cta` と統一感を持たせる）
2. 相談する／資料請求するの2導線
3. 問い合わせ後の流れの簡易説明（任意）

## 7. 必要な写真素材のリスト

- ブランド全体トーンのヒーロービジュアル（TOP用、暗めで上質な外観・内観）※既存LPと共通素材の流用可否を要確認
- モデルハウス／施工実例の外観写真（複数角度、日中・夕景）
- 構造・性能：施工中の骨組み・断熱材施工シーン、耐震関連ディテール（金物・接合部など）
- 外装：外壁材・屋根材のクローズアップ（質感が伝わるマクロ撮影）、経年変化がわかる比較写真（あれば）
- 内装・素材：床材・建具・造作家具のディテールカット、素材サンプル（スウォッチ）撮影、光の入り方が分かるカット
- 設備：キッチン・浴室・洗面・トイレの実使用シーン（生活感のある構図）
- 環境・省エネ：太陽光パネルや断熱まわりの外観、（数値訴求を補うインフォグラフィック用の背景写真）
- 人物カット：設計者・現場監督・職人のポートレートまたは作業風景（「思想を語る人」を可視化するため）
- 暮らしのシーン：家族が実際に過ごすカット（各カテゴリの「暮らし目線」導入に使用）
- アイコン・図版（写真ではないが要制作）：断熱等級・耐震等級などの認証マーク、比較表用のピクトグラム

## 8. 必要なテキスト原稿のリスト

- コアメッセージ／サイト全体のステートメントコピー（TOPヒーロー用）
- 選定思想ページ：判断基準3〜4軸それぞれの定義文＋説明文（各300〜500字目安）
- 各カテゴリページ共通：
  - 導入文（そのカテゴリでFORTが向き合う課題）
  - 仕様項目ごとの「仕様名＋選定理由」原稿（各150〜250字程度、2〜4項目×5カテゴリ）
  - シリーズ間差異の説明文
- 現場・設計者インタビュー原稿（一次情報、任意だが説得力の要）
- FAQ：Q&A原稿一式（標準/オプションの境界、シリーズ差、変更可否、メンテナンス関連など想定10問前後）
- CTA文言（TOP、各カテゴリ末尾、専用CTAページで表現を微調整）
- メタ情報：各ページのSEO用タイトル・ディスクリプション
- 用語解説（断熱等級・耐震等級など専門用語の平易な言い換え）
- 既存LP（3シリーズ）との関係性を説明する橋渡し文

## 9. 実装前に確認すべきこと

- **仕様データの確定リスト**：カテゴリごとに実際に採用しているメーカー名・型番・グレードの最新かつ正式なリストを誰が提供するか（設計部門／購買部門など）。
- **シリーズ間の仕様差**：STYLE/PRO/DESIGNで標準仕様が同一か、一部異なるか。異なる場合、本サイトの情報構造（共通仕様ページ＋シリーズ別差分表現）に影響するため先に確定が必要。
- **サイトの実装形態**：既存LPのように「単一HTMLブロックをCMS埋め込み」する形式か、独立した複数ページ構成のサイトか（サイトマップの実現方式に直結）。
- **更新運用体制**：仕様は建材メーカーの型番変更・年次改定などで更新が発生し得る。誰が・どの頻度で・どう更新するか（原稿修正フローと承認者）。
- **ブランドガイドラインの流用可否**：既存LPのカラー変数（`--fsl-gold` 等）・フォント・アニメーション仕様をそのまま使ってよいか、専用のガイドラインが別途あるか。
- **写真素材の権利関係**：自社モデルハウスの撮り下ろしが可能か、メーカー提供画像を使う場合の許諾範囲、人物が写る場合の肖像権処理。
- **一次情報（インタビュー等）の実現可否**：設計者・職人のコメントを撮れる体制があるか。無い場合はテキストのみでの説得力担保を検討する必要あり。
- **SEO・想定流入経路**：検索流入をどこまで狙うか（カテゴリページ単位のキーワード設計に影響）。
- **デバイス比率**：既存LP同様スマートフォン優先の設計で問題ないか。
- **他サイトとのナビゲーション統合**：コーポレートサイトや `fort-series-lp` とのグローバルナビ・パンくず・相互リンクの扱い。
- **地域差の有無**：施工エリアによって標準仕様が変わる可能性があるか（ある場合、ページ設計に地域切り替えが必要になる）。
- **競合調査・差別化ポイントの社内合意**：「メーカー名の羅列にしない」という方針自体の社内承認と、実際にどこまで踏み込んだ言語化が許容されるか。
