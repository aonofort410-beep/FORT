# FORT WordPressテーマ 導入・編集ガイド

この `fort-theme` フォルダが WordPress テーマ本体です。
**プラグインなし**で、施工事例・スタッフ・イベント・お知らせを管理画面から追加・編集できます。

---

## 1. インストール（最初の1回だけ）

### 方法A：ZIPでアップロード（かんたん）
1. `fort-theme` フォルダを **ZIP圧縮**する（フォルダごと `fort-theme.zip` に）
2. WordPress管理画面 → **外観 → テーマ → 新規追加 → テーマのアップロード**
3. `fort-theme.zip` を選んで **今すぐインストール → 有効化**

### 方法B：FTP/サーバーに直接置く
- サーバーの `wp-content/themes/` の中に `fort-theme` フォルダをそのまま置く
- 管理画面 → 外観 → テーマ で「FORT」を **有効化**

---

## 2. 最初の設定（5分）

1. **トップページの指定**
   設定 → 表示設定 → 「ホームページの表示」を**「固定ページ」**にし、
   ホームページ用に空の固定ページ（例：「ホーム」）を作って指定。
   ※ デザインは `front-page.php` が自動で表示します（中身は空でOK）。

2. **お知らせページ**：上の「投稿ページ」に空の固定ページ（例：「お知らせ」）を指定。

3. **パーマリンク**：設定 → パーマリンク → 「投稿名」を選んで保存
   （これを一度やらないと施工事例などのページが404になります）

4. **キャッチコピー・電話番号**：外観 → カスタマイズ →
   「FORT：トップのキャッチコピー」「FORT：連絡先」で編集できます。

---

## 3. コンテンツの追加・編集（毎回ここだけ）

管理画面の左メニューに、専用の項目が増えています。

| メニュー | 役割 | 入力するもの |
|---|---|---|
| **施工事例** | 事例の追加 | タイトル／アイキャッチ画像（メイン写真）／本文（写真・文章）／抜粋（リード文）／右の「施工事例の詳細」（エリア・価格・面積など） |
| **スタッフ** | スタッフ紹介 | 氏名（タイトル）／顔写真（アイキャッチ）／「スタッフ情報」（部門・職種・英字名・資格） |
| **イベント** | 見学会など | タイトル／「イベント情報」（開催日・種別・場所）／本文 |
| **お知らせ** | ニュース | タイトル／本文／カテゴリ（標準の「投稿」です） |

### ポイント
- **写真＝アイキャッチ画像**：各投稿の編集画面 右側「アイキャッチ画像」に設定すると、一覧やトップに自動表示されます。
- **施工事例の詳細ページ**：本文に画像ブロックや見出しを入れると、そのままギャラリー・ストーリーになります。
- **並び順（スタッフ）**：編集画面の「順序」（page-attributes）の数字が小さい順に並びます。

---

## 4. 旧サイト（静的HTML）について
- 変換元の `index.html` などの静的ファイルは、このリポジトリにそのまま残しています（プレビュー用）。
- WordPress では使いません。テーマ（`fort-theme`）が表示を担当します。

---

## 5. 専用レイアウトの独立ページ（構造・性能 など）

下記のページは、それぞれ専用テンプレートを用意しています。
**固定ページを作成し、テンプレートを割り当てる**だけで独立ページになります。

### 作り方（各ページ共通）
1. 固定ページ → 新規追加
2. タイトルを入力（例：構造・性能）
3. 右側「ページ属性 → テンプレート」で対応テンプレートを選択
4. **URLスラッグを下表の指定どおりに設定**（メニューやリンクがこのスラッグ前提です）
5. 公開

| 作るページ | 選ぶテンプレート | スラッグ（重要） |
|---|---|---|
| 構造・性能 | 構造・性能 | `performance` |
| 家づくりの流れ | 家づくりの流れ | `flow` |
| 商品ラインナップ | 商品ラインナップ | `lineup` |
| 特集 | 特集 | `feature` |
| FORT PRO 規格プラン | FORT PRO 規格プラン | `fort-pro` |
| スタジオ・モデルハウス | スタジオ・モデルハウス | `studio` |
| 会社概要 | 会社概要 | `company` |
| FORT DESIGN（自由設計・特設） | FORT DESIGN（自由設計・特設） | `fort-design` |
| お客様の声（FORT FAMILY） | お客様の声（FORT FAMILY） | `family` |
| ご来場予約 | ご来場予約 | `visit` |
| 資料請求 | 資料請求 | `request` |
| お問合せ | お問い合わせ | `contact` |

> スラッグは編集画面のタイトル下「パーマリンク」で設定できます（半角英字）。
> 上の表どおりにすると、目次メニュー・フッター・ページ間リンクがすべて正しくつながります。

- これらのページの本文（数値や文章）は、現状テンプレート内に直接書かれています。
  文言を変えたい場合は該当 `template-***.php` を編集するか、ご依頼ください。
- 地図（スタジオ）は Googleマップの埋め込みコードに差し替え可能です。

## 6. ブランドサイト化（v2）で増えたこと

### トップページの構成
HERO → ABOUT → SELECTED WORKS → HOUSE → JOURNAL → MOVIE → EVENT → PLACE → VISIT

- **写真や記事が無いセクションは自動で表示されません**（仮の内容は出しません）。
  - SELECTED WORKS：アイキャッチ画像のある施工事例が1件以上あると表示
  - JOURNAL：「JOURNAL」に記事が1件以上あると表示（メニューにも自動で出ます）
  - MOVIE：外観 → カスタマイズ →「FORT：MOVIE（YouTube）」に動画URLを入れると表示。クリックするまで動画は読み込まないので、ページは重くなりません
- LIFE WITH FORT（暮らしの写真）は、写真がそろってから追加します。

### イベント（URL は /info/）
編集画面の「イベントの地域・状態・期間」で入力します。

| 項目 | 内容 |
|---|---|
| 地域 | 岡山 / 福山（一覧の切り替えに使います） |
| 種類 | **期間限定**（見学会など）／**常設**（相談会・モデルハウスなど） |
| 受付状態 | 受付中 / 満席 / 受付停止 / 終了 |
| 開始日・終了日 | 期間限定のみ。**終了日を過ぎると自動で「終了」になり、一覧から消えます** |

常設のイベントは日付で終了しません。やめるときは受付状態を「受付停止」にしてください。

### メニュー
WORKS / HOUSE / EVENT / JOURNAL / PLACE / ABOUT / VISIT に整理しました。
HOUSE・PLACE・ABOUT などの新しいページがまだ無い間は、既存のページ（商品ラインナップ・スタジオ・会社概要）へ自動でつながるので、リンク切れにはなりません。

### その他
- 外観 → カスタマイズ →「FORT：連絡先」に Instagram のURLを入れると、フッターにリンクが出ます。
- スマホ画面下の大きな固定ボタンは外し、ヘッダーに控えめな「VISIT」を置きました。

## 7. 施工事例（WORKS）の入れ方 — 作品集として

編集画面の「作品集としての情報」に入力します。**空欄の項目はページに表示されません。**

| 項目 | 使われる場所 |
|---|---|
| 地域 / 平屋・二階建て / 商品 | 一覧の絞り込み、事例名の下の小さな表記 |
| この家の背景 | 詳細ページ BACKGROUND |
| 設計上の工夫 | 詳細ページ DESIGN（黒い帯）。**「FORTとして、なぜこの設計にしたのか」を書きます** |
| 暮らし | 詳細ページ LIFE |
| YouTube動画のURL | 詳細ページ MOVIE（クリックしてから読み込み） |

- **写真**：アイキャッチ画像＝メイン写真。ほかの写真は本文に「ギャラリー」ブロックで並べます（2列・3列が誌面レイアウトになります）。
- **特徴で絞り込みたいとき**（中庭・吹き抜け など）：右側の「事例カテゴリ」にチェックします。
- 所在地・延床面積・間取り・竣工・構造性能・家族構成・価格は「施工事例の詳細」欄へ。**公開してよいものだけ**入れてください。
- **設計担当者の名前・顔写真・コメントは載せない設計です。** 担当が変わっても、ページの価値が変わらないようにしています。
- 一覧は大きい写真と小さい写真が交互に並ぶ「誌面」のレイアウトです。メイン写真は横長・縦長どちらでも自動でトリミングされます。

---

## 8. イベント（/info/）の入れ方

- **一覧**は「期間限定の見学会」と「いつでも参加できる相談会（常設）」の2段に分かれます。どちらも岡山／福山で切り替えられます。
- **詳細ページ**に出る項目（空欄なら非表示）：見られること／相談できること／日時・時間／場所／所要時間／駐車場／予約方法
- **予約ボタン**は、地域とイベント名を予約フォームへ引き継ぎます。満席・受付停止・終了のときはボタンが消え、スタジオ来場予約へ案内します。
- 下に同じ地域の施工事例が3件、自動で並びます。
- **モデルハウス（例：玉野・下加茂）**は「種類：常設」のイベントとして登録してください。以前の一覧に固定で書いていたモデルハウス欄は、写真と情報が古くならないよう投稿で管理する形にしました。
- 期間限定で開始日があるイベントは、Google向けにイベント情報（構造化データ）を自動で出します。

---

## 9. モデルハウスの追加（管理画面「モデルハウス」）

1. 左メニュー **モデルハウス → 新規追加**
2. タイトル（例：福山下加茂モデルハウス）、アイキャッチ画像（メイン写真）、本文に写真ギャラリー
3. 「モデルハウスの情報」に入力：地域／公開状態／場所／見学できる時間／見学方法／所要時間／駐車場／この家で見られること
4. 公開

- **公開状態を「公開終了」にすると、一覧から自動で消えます**（ページは「公開終了」と表示され、スタジオ来場予約へ案内）。
- 表示される場所：トップの EVENT の下、イベント一覧（/info/）の「いつでも見に行ける、モデルハウス」、各モデルハウスのページ（/model-house/スラッグ/）
- テーマを有効化したとき、モデルハウスが1件も無ければ「福山下加茂モデルハウス」を**下書き**で自動作成します。写真と情報を入れて公開してください。
