# images フォルダ（写真の置き場所）

このフォルダに、サイトで使う写真を入れてください。
**下の「ファイル名」と同じ名前**で保存すると、自動でサイトに表示されます。

| ファイル名 | 使われる場所 | 内容（今回いただいた写真） |
|---|---|---|
| `hero.jpg` | ファーストビュー背景 ／ 施工事例①「中庭とつながるブラックモダンの家」 | 写真① 木スリット天井のモダンなLDK |
| `exterior.jpg` | 施工事例②「平屋」 ／ 施工事例⑥「プライベートハウス」 ／ RESERVE背景 | 写真⑤ グレーの外観 |
| `kitchen-view.jpg` | 施工事例③「景色を楽しむリゾートスタイルの家」 ／ 施工事例⑤「開放的なLDKの家」 | 写真② 海が見えるキッチン |
| `ldk.jpg` | 施工事例④「ホテルライクな二階建ての家」 ／ EVENTの写真 | 写真③ 明るい白のLDK |
| `niche.jpg` | CONCEPTの写真 | 写真④ 木のニッチ（間接照明） |

## 写真の入れ方（GitHubのサイト上で簡単にできます）

1. GitHubで `images` フォルダを開く
2. 右上の「**Add file**」→「**Upload files**」
3. 5枚の写真をドラッグ＆ドロップ
4. ファイル名を上の表のとおりに変更（例：`hero.jpg`）
5. ブランチ `claude/elegant-shannon-izgn32` を選んで「Commit changes」

> ※ 写真の形式は `.jpg` を想定しています。`.png` などで入れたい場合は教えてください。
> ※ 1枚あたり 2〜3MB 以下に圧縮すると、サイトの表示が速くなります。

## スタッフページ（staff.html）の写真

スタッフの顔写真は **正方形（推奨 800×800px）** がきれいに表示されます。
未配置の間は「FORT」の仮画像が出ます。

| ファイル名 | 部門 |
|---|---|
| `staff-sales-01.jpg` / `staff-sales-02.jpg` | 営業 |
| `staff-design-01.jpg` / `staff-design-02.jpg` | 設計 |
| `staff-construction-01.jpg` / `staff-construction-02.jpg` | 工務 |
| `staff-admin-01.jpg` | 総務 |

> スタッフを増やすときは、`staff.html` の `<li class="member"> … </li>` を
> コピー＆ペーストして、名前・肩書き・紹介文・画像ファイル名を書き換えてください。

## 会社概要・スタジオページの写真

| ファイル名 | 使われる場所 |
|---|---|
| `company-message.jpg` | 会社概要：代表メッセージの写真（推奨 800×600px） |
| `studio-okayama.jpg` | スタジオ案内：岡山スタジオの写真（推奨 1200×800px） |
| `studio-fukuyama.jpg` | スタジオ案内：福山スタジオの写真（推奨 1200×800px） |
| `map-okayama.jpg` | 岡山スタジオの地図（GoogleマップのiframeでもOK） |

> 未配置の間は「FORT」の仮画像が表示されます。
> 地図は画像でなく、Googleマップの「埋め込みコード(iframe)」を該当の `<img>` と
> 差し替えると、実際に動かせる地図になります。
